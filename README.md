# Support Copilot — демо

Небольшой интерфейс помощника для разбора обращений игроков Grand Mobile. Прототип показывает два типа обращений: жалобы на игроков и игровые репорты.

## Возможности демо

- показывает очередь вымышленных обращений и историю сообщений;
- фильтрует список по типу и ищет по обращению;
- показывает демонстрационную сводку, категорию и следующий шаг;
- предлагает редактируемый черновик ответа;
- копирует сводку или ответ;
- позволяет отметить обращение решённым.

Подсказки в интерфейсе демонстрационные. Они не являются вердиктом или результатом анализа конкурсного датасета. Решение должен принимать уполномоченный сотрудник после проверки правил и доступных доказательств.

## Запуск в Windows

1. Сохраните `index.html`, `styles.css`, `app.js` и `README.md` в одной папке.
2. Дважды щёлкните `index.html`, чтобы открыть сайт в браузере.
3. После изменений сохраните файл и обновите страницу клавишей `Ctrl+R`.

Установка программ и запуск сервера не требуются. Для Google Fonts нужно подключение к интернету; без него браузер использует системный шрифт.

## Файлы

- `index.html` — разметка страницы и подключения CSS и JavaScript;
- `styles.css` — оформление и адаптация для небольших экранов;
- `app.js` — вымышленные примеры и логика интерфейса;
- `README.md` — описание проекта и инструкция запуска.
